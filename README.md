# 🔥 Modern Login UI – Smooth Sign In & Sign Up Animation

A modern and clean login interface with smooth sign in and sign up animation transitions.  
Built using HTML, CSS, and JavaScript to practice modern UI design and user interaction.

---

## ✨ Features
- Smooth animation between Sign In & Sign Up
- Modern clean UI design
- Responsive layout (mobile & desktop)
- Simple and beginner-friendly code
- Easy to customize
